Mechanism: preserve coverage, remove penalized mass — conditional algebra

Under the requested distance-weighted Tversky definition used by the shared template, let T be kernel-weighted coverage over truth pixels, S emitted prediction mass, M summed nearest-truth kernel credit at prediction pixels, and N truth count. For binary dots:

D = T + alpha*(S - M) + beta*(N - T)
DTI = T / D
alpha = 0.2; beta = 0.8

A new dot changes truth coverage by deltaT and earns nearest-truth credit k. Then:

new DTI > old DTI
iff deltaT > alpha * old_DTI * (deltaT + 1 - k)

Only in the special case deltaT = k does this reduce to k > alpha * old_DTI. In general, one dot can cover multiple truth pixels, so deltaT and k must not be conflated. The scalar nearest-truth credit is not the same thing as marginal coverage.

This explains why sparse placement and deleting redundant/low-credit dots can improve DTI. It does not prove which hidden fault pixels were covered, that all catalogue-near dots are useless, or that catalogue incompleteness has any universal distance law. Hidden organizer labels are unavailable. Reported sequential improvements are consistent with an emission-efficiency explanation, not causal geological proof.

Can we beat it?

Possibly, but no verified result from this session supports that claim. A defensible path requires new ranking evidence and less redundant mass, not an arbitrary rescaling, random jitter, renamed file, or a pruned copy of the champion. Those would not meet the user's uniqueness protocol.

The fixed magnetic-contact-termination experiment is a negative result. See the results page for HOLDOUT-DTI with evaluator version, withheld positives and confidence intervals. It underperforms its random sparse control at similar mass, and fails the literal surface overlap gate. Neither observation can be converted into a projected leaderboard score.

Key scientific distinction

Fault traces are the competition prediction target; geothermal vents are not the direct labels. An interpreted discontinuity may matter for fluid flow, but does not establish permeability, temperature, a vent, or a viable geothermal resource. Potential-field contact truncations may be lithologic boundaries or dike endpoints rather than faults. The proposed mechanism is a falsifiable hypothesis, not a remotely verified discovery.

Read line by line, this table is the single most important calibration fact in the repo:

  1. Thinning helps on both instruments (solid → dotted: live-reported 0.1922 → 0.2600; holdout 0.0655 → 0.0919). Removing kernel-redundant mass raises credit per dot; the marginal bar for one more non-redundant dot is k > alpha*DTI ≈ 0.2*0.26 ≈ 0.052 (exact two-sided form in the main text).
  2. Catalogue-flank pruning (D2.8 → H33) helps live-reported (+0.0178) and destroys catalogue holdout (0.0919 → 0.0037, below random). This is expected once the targets are distinguished: live truth is expert-mapped new faults, so dots hugging the known catalogue earn ~no credit and pruning them is pure gain; holdout truth is catalogue pieces, so the same pruning deletes near-truth dots and the far-field remainder (median 1.96 km from the catalogue) cannot recover withheld traces. Any claim of the form "X beats H33 on catalogue holdout, therefore X beats 0.2778 live" is false; random dots also beat H33 on this instrument by 11×.
  3. Why H33 plausibly earned its reported live value (conditional on the user report): it combines (i) the family's strongest ranking surface (H19-5 multiline-corroborated), (ii) Poisson-style thinning to kernel scale so each dot buys nearly independent 300 m coverage, (iii) deletion of the 6,436 lowest-expected-credit catalogue-flank dots (D2.8→B2 total), raising mean credit/dot, and (iv) binary amplitude with all-finite zeros export (format safety, not score). No new detector was trained for B2; the gain is emission efficiency on an already-good ranking.
  4. Can a new field beat 0.2778 live? Only with higher credit density at comparable mass: a ranking whose top ~38k thinned dots land within 300 m of new faults more often than H19-5's do. Pruning alone is exhausted (B2 already removes the flank; further cuts remove coverage). The public leader read this session is 0.4413 (evidence/leaderboard_read.json, organizer page read 2026-10-20) — about 1.59× the reported H33 value, so the required credit-density gain to lead is large. E2's novel ranking ties H19-solid efficiency at one-third the mass on catalogue recovery but loses to dotted D2.8 there (Δ −0.0273, CI entirely negative); its live value is unknown and no projection is made.
  5. Two-round caveat (unresolved, selector must note): the organizer problem page (fetched 2026-10-20) says one selected GeoTIFF is scored first against private new faults, then rescored against an expanded label set after expert review of all submissions. Whether the expanded set includes the known catalogue itself is not stated in the fetched text. The family-wide zero-on-catalogue + flank-prune strategy is optimal for round 1 as described; if round 2 includes known faults in G, the same strategy forfeits that coverage. A single file must serve both rounds, so this ambiguity is a first-order strategic risk, flagged here rather than resolved by assumption.
  6. Bridge irregularity: data/bridge/sample_submission.tif is not the all-zero sample described on the problem page — measured this session, its positive pixels are exactly the 60,988 catalogue pixels (identical support to existing_faults.tif). Only its finite-cell footprint is used. Never submit the bridge sample as a prediction.
