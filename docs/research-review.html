Literal-protocol review — 2026-10-20

Decision: DO NOT SUBMIT; archived downloads are for review only

No new TIFF was generated. No new geological experiment was run. No competition slot was used. This is a negative deliverable, not completion of the request for a new protocol-compliant submission. The supplied prompt has no identifiable single-method lane paragraph; the prior handoff's supervised within-halo ranking is the deferred lane, not an invented or authorized assignment.

Canonical current pointers: evidence/review/run_card.json and evidence/review/literal_protocol_audit.json; their public copies are under docs/downloads/. evidence/current_protocol_review.json and evidence/literal_protocol_review.json are historical compatibility receipts and do not supersede the canonical current card.

The current prompt explicitly requires a stop when forward dot overlap exceeds 70% within 3 pixels, or rank correlation exceeds 0.90. Earlier work changed forward overlap to mutual overlap without user approval. That change does not satisfy the current prompt. A low reverse overlap or rank correlation cannot cancel a high forward overlap.

Validation plan, deferred — not a measured result

Once a separately authorized protocol resolves the literal-gate conflict, test only the first candidate. Keep the shared evaluator and writer. Freeze the mass, folds, feature list and gates first. Hide whole fault components with the shared buffer, regenerate catalogue-derived features from visible faults only, and mask visible faults pixel-exactly. Compute each raw/derived feature-alone AUC before interpreting any joint result; >0.90 is a leakage alarm, including inverse-predictive features as a conservative diagnostic. All feature fitting, scaling and SGMC proxy labels must exclude the test quadrant and its buffer. SGMC is proxy training truth, not an inference feature; its overlap with QFaults must be quantified, not called independent truth.

Evaluate pooled HOLDOUT-DTI (shared evaluator gems57-pooled-hide-v2, alpha 0.2, beta 0.8, 300m triangular kernel), withheld-positive count, and paired spatial-bootstrap 95% intervals. Re-evaluate D28 and the current best on exactly the same folds/mass; compare B′ separately as a proxy, not as HOLDOUT-DTI or an organizer score. The cached E2 D28 HOLDOUT-DTI is an archived reference in its original run card, not a newly rerun baseline. No promotion without a matched best-baseline comparison, canaries, both-stage literal uniqueness, format validation and a separate selector decision. Stop after at most three experiments or two hours. No automatic weekly submission.
