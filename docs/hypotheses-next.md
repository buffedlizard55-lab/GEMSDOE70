**Source/availability check.** Each ranked proposal uses only bands already present in the locally restored, pinned owner mirror; **no new external binary is needed to compute its proposed features**. [USGS GeoDAWN](https://www.usgs.gov/data/geodawn-airborne-magnetic-and-radiometric-surveys-northwestern-great-basin-nevada-and) documents the flight-block geometry, unequal line spacing and variable clearance: acquisition seams are explicit competing explanations, not assumed faults. Do **not** label that optional experiment viable until acquisition, licensing and coverage are verified.

**Gate before any method run.** A candidate must first have an assigned method paragraph and a preregistered comparison to a *same-split, visible-only* current best (not a frozen full-catalogue TIFF). Withhold whole fault components with a buffer; derive catalogue features exclusively from visible faults; mask visible faults pixel-exactly; canary every raw and derived feature alone (AUC > 0.90 means possible leakage).
