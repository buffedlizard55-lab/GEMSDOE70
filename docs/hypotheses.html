Fixed first experiment

No external-data-dependent idea is asserted viable. All named layers are already obtainable in the restored, SHA-pinned owner mirror. Their descriptions are metadata, not independent proof of the precise inversion or units.

  • Smooth RTP with Gaussian sigma one pixel; compute magnetic gradient magnitude, then smooth its amplitude with sigma two pixels.
  • Smooth gravity anomaly with sigma three pixels; compute its unit normal and tangent.
  • Feature termination: absolute directional derivative of magnetic edge amplitude along that tangent.
  • Feature gravity_edge: magnitude of the smoothed gravity gradient.
  • Feature basement_normal: absolute projection of the sigma-three basement-depth gradient onto the gravity normal.
  • Rank each feature with average ties over the finite feature domain (no catalogue input). Candidate field is the geometric mean of these three ranks. Ablation omits termination.
  • Continuous evaluation field retains the upper two percent of ranks, linearly rescaled to [0,1]. This is a fixed surface transform, not final dot placement, not a calibrated probability.
  • Test every raw input and derived feature alone with holdout AUC and HOLDOUT-DTI before interpreting the joint field. AUC > 0.90 stops the run as suspected leakage.
  • Shared buffered_component_draw: seed twenty, whole connected catalogue components withheld in four spatial quadrants, three-pixel catalogue feature collar and twelve-pixel boundary erosion. No catalogue-derived predictor is used.
  • Shared evaluate_holdout.py: pool weighted terms; paired physical twenty-kilometre cluster bootstrap, one thousand draws, ninety-five percent interval. Catalogue recovery is not validation on hidden organizer labels.
  • Compare ablation and a fixed random sparse control; a compatible current-holdout-best implementation is not available in this checkout. No promotion without that comparison.
  • Before any final dots or submission writing, compare the candidate surface to a SHA-verified registry witness with the literal shared uniqueness tool. Any positive duplicate witness is sufficient to stop; it is not sufficient to certify uniqueness. Never scan past a stop to search for a loophole.
  • At most one scientific experiment planned; never more than three or two hours. No competition upload or weekly slot.

Scientific limits

Potential-field inversions are nonunique. Magnetic amplitude changes can reflect magnetization rather than displacement; gravity and basement depth may share inversion priors and are not necessarily independent evidence. This test can falsify a useful ranking but cannot establish a geothermal vent, temperature, permeability, or economic resource. The actual target is new fault traces, as described by the organizer's fault-detection reference notebook, not a vent catalogue.

H-P5-1 supervised within-halo ranking on the SGMC off-catalogue proxy

  • Hypothesis. SGMC off-catalogue fault pixels (the B′ population: SGMC ∧ ¬catalogue ∧ footprint ∧ d_catalogue ≥ 3 px) are separable from the halo background by a gradient-boosted model over the cached 19-band physics stack plus visible-catalogue geometry, and that ranking transfers both to catalogue-withheld segments (instrument A) and to spatially held-out quadrants (instrument B′ leave-one-quadrant-out). This is the "within-halo information" that docs/h33-analysis.md identifies as the only route past emission geometry.
  • Layers. All 19 bands of training_features.tif (mag_anom, rtp, tmi_hg, geod_2ndinv, iso_grav_anom_slope, tc, geod_shearrate, geod_dilaterate, tmi_vg, deq_n100a15, iso_grav_anom_vg, det_elev, iso_grav_anom, tmi, depth_to_base_surf, ieq_n100a15, cond_surf, iso_grav_anom_hg, det_elev_slope) plus three catalogue-geometry features (d = distance to visible catalogue, u, v = along/across-strike tip kernels, all from method_v2.tip_kernels). 22 features, no others.
  • Mechanism. sklearn.ensemble.HistGradientBoostingClassifier (random_state 70520, max_iter 300, learning_rate 0.06, max_leaf_nodes 31, min_samples_leaf 40, l2 1.0, early_stopping True, validation_fraction 0.1). Training rows: all in-band proxy positives (measured 38,757) + 150,000 uniform in-band negatives (seed 70521). Allowed domain = the P4 band: valid ∧ ¬catalogue ∧ 2.4 ≤ d ≤ 32 px (measured 2,768,584 cells; 63.7 % of B′ truth lies inside it — the band caps reachable truth and widening it is deliberately NOT part of this experiment). Leave-one-quadrant-out over the shared holdout.quadrant_ids split: four models for evaluation, one production model trained on all quadrants.
  • Emission. The measured P4 design, unchanged: one dot per 7×7-px stratum at the stratum maximum of the model score, keep the best 37,654 strata, 5-px Euclidean NMS. Fixed mass 37,654 binary dots, zero on the catalogue, zero outside the footprint.
  • Non-fault mimic (named). SGMC cartographic generalization: mapper habit and digitization conventions (line-work following map-unit contacts, section lines, or scanner artifacts) can be learned as if geology. Such structure transfers to the proxy labels but not to organizer truth.
  • Instruments and arms. A: shared buffered_component_draw (seed 20, buffer 3 px, boundary 12 px), candidate scored with the production model but fold-visible geometry. B′/B: quadrant regions eroded 12 px, candidate dots in quadrant k from LOQO model k (full-catalogue geometry, matching its training). Arms: candidate, random control (37,654 uniform on valid ∧ ¬visible), h33_reference, and p4_reference (the published Phase-4 TIFF, hash-pinned) so the run is compared against the current holdout best family, not only H33.
  • Canaries (rule 4). (i) every feature alone vs instrument-A withheld truth — STOP if any AUC

    0.90; (ii) every feature alone vs the proxy labels — reported, because it measures what the model can memorize (d is expected to be high: proxy traces hug the catalogue; that is label structure, not feature leakage, and is disclosed rather than hidden); (iii) LOQO out-of-fold model AUC vs the proxy — STOP if > 0.90.

  • Uniqueness (rule 1). Surface Spearman vs the 62 archived registry rasters BEFORE placement (stop if ρ > 0.90); final dot audit after writing (mutual 3-px overlap > 0.70 or ρ > 0.90 → duplicate → negative, no promotion).
  • Gates (verdict promote iff ALL hold). gate A: candidate A-DTI ≥ H33 A-DTI; gate B′: paired Δ vs H33 > 0 with 95 % CI lower bound > 0; uniqueness cleared; shared validator all checks pass. Any failure → negative. Weekly slots remain 0; promotion to a real slot is a separate selector step.
  • Registered honesty constraints. B′/B share the label source with training (LOQO spatial split only) — they are PROXY-DTI (LOQO), partially in-sample; instrument A is the only label-independent gate, which is why both gates are required. Instrument A itself has a contamination channel: SGMC re-draws of withheld catalogue segments that sit ≥ 3 px from the catalogue can appear in the training labels and within kernel range of A truth; the run measures and discloses the fraction of A-truth pixels within 3 px of proxy pixels. Phase-4 measured the supervised-free baseline at A 0.0730 / B′ 0.0812; H33 at A 0.0037 / B′ 0.0938.

Phase-5 implementation amendment (2026-10-20, before any score was seen)

The registered emission ("one dot per 7×7-px stratum at the stratum maximum, best 37,654 strata, 5-px NMS, fixed mass 37,654") is under-determined for a spiky surface: on the first execution the model surface allowed only 34,587 block-argmax dots under NMS (the Phase-4 smooth halo never hit this). The run stopped at the mass invariant before any evaluation. Amendment, fixed before any DTI was computed: pass 1 stays byte-identical to the Phase-4 operator (blocks in score order, dot at the stratum maximum when NMS-feasible); only if pass 1 places fewer than 37,654 dots does a second pass place one dot at the best NMS-feasible positive-score cell of the highest-scoring strata that remain empty (positive cells are exactly the allowed-domain cells, so every dot stays off-catalogue and inside the footprint). One dot per stratum and the fixed mass are preserved; no threshold, mass or domain changed. Disclosed in the run card as emission_topup.
