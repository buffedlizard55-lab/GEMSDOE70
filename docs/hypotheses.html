Pre-Specified Validation, Uniqueness & Release Protocol (Experiment 2)

  1. Untouched Spatial Holdout (seed=702): Whole connected fault components withheld in four spatially eroded quadrants (buffer_px=3, boundary_px=12) via unmodified vendor/gems57/holdout.py:buffered_component_draw. All out-of-fold models train strictly on the 3 non-test spatial quadrants using ONLY fold['visible'] (zero withheld pixels, zero catalogue distance features in X_train).
  2. Feature-Alone Leakage Canary: Every raw and engineered feature must satisfy max(AUC, 1 - AUC) <= 0.90 on the exact evaluation domain before any joint training is accepted.
  3. Apples-to-Apples Same-Split Comparators: Candidate H70-2A is tested head-to-head on identical spatial blocks against:
  4. GEMS49_OrthoGate (same-architecture reimplementation of GEMSDOE49's published gate_ortho_w0.25 construction — multiscale det_elev_slope edge × structure-tensor coherence × cross-gradient orthogonality gate — on identical visible masks; not their code or bytes),
  5. GEMS70_E1_ContactTermination (Experiment 1 method on identical split),
  6. SingleBand_ElevSlope (single-layer 100 m topographic slope dotted),
  7. Random_Sparse_Control (matched dot count),
  8. Domain ablations (Ablation_NoGate_NoRoad = raw out-of-fold model surface dotted identically; Ablation_NoCrossScale = model retrained per fold without any 1 m LiDAR / 10 m DEM features, dotted identically). Candidate must strictly beat ALL comparators (paired 95% bootstrap CI > 0 vs GEMS49_OrthoGate_40k, SingleBand_ElevSlope, GEMS70_E1, and Random_Sparse_Control) or promotion stops as negative.
  9. Full 940-Raster Two-Stage Uniqueness Audit (vendor/gems57/uniqueness.py):
  10. Checked on both the pre-placement continuous surface AND the final binary dot field against all 940 SHA-256 verified grid-matching rasters across all 71 repositories + quarantined H70-C.
