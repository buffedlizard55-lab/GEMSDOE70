Literal-protocol review — 2026-10-20

Decision: DO NOT SUBMIT; archived downloads are for review only

No new TIFF was generated. No new geological experiment was run. No competition slot was used. This is a negative deliverable, not completion of the request for a new protocol-compliant submission. The supplied prompt has no identifiable single-method lane paragraph; the prior handoff's supervised within-halo ranking is the deferred lane, not an invented assignment.

The current prompt explicitly requires a stop when forward dot overlap exceeds 70% within 3 pixels, or rank correlation exceeds 0.90. Earlier work changed forward overlap to mutual overlap without user approval. That change does not satisfy the current prompt. A low reverse overlap or rank correlation cannot cancel a high forward overlap.

Validation plan, deferred — not a measured result

Once a separately authorized protocol resolves the literal-gate conflict, test only the first candidate. Keep the shared evaluator and writer. Freeze the mass, folds, feature list and gates first. Hide whole fault components with the shared buffer, regenerate catalogue-derived features from visible faults only, and mask visible faults pixel-exactly.
