Supplied prompt contains no single method paragraph. Declared lane for this session, one method only:

Stay inside this lane. No blending with E2, no rescaling of H33 dots, no new external download.

## E4 frozen specification

Inputs (`.cache/data/training_features.tif` SHA 4371c82…, `.cache/gems_data/external/*` SHAs in manifest, `.cache/data/existing_faults.tif`, `sample_submission.tif`, `sgmc_faults_100m.tif` from /tmp/60GEMSDOE clone). Grid/sample/catalogue from shared `gems57.grid.load_grid`. Vendor code byte-pinned and unmodified.

1. `valid0 = footprint & finite for all 39 bands`. `valid = binary_erosion(valid0, 12)` applied **after** all filtering. No output outside `valid`. This fixes the E1 order flaw (erosion before fill would leak).
2. Fill non-valid cells not needed for HGB (training uses only valid pixels); no nearest-fill for ranking because HGB handles only valid samples. Ranking field defined only on `valid`.
3. Proxy truth: SGMC raster `>0` minus catalogue, footprint, plus `dcat >=3 px` for prime (B′). Negative: `valid & ~proxy`. Positive prime 62,649 pixels. Negative pool sampled 120k per LOQO fold.
4. LOQO: 4 spatial quadrants by median footprint row/col, each eroded 12 px as the scoring domain (same as `buffered_component_draw` domains). For fold q, train on `valid & ~region_q & proxy_prime` positives and sampled negatives; predict on `valid & region_q`. Gives OOF probability for every `valid` pixel (outside scored domains filled by global model trained on all folds). No catalogue-derived predictor enters training.
5. Model: `HistGradientBoostingClassifier(max_depth=6, max_iter=100, learning_rate=0.1, min_samples_leaf=30, random_state=20)`. Same hyperparameters for each LOQO fold and for the global refit (all positive prime + 200k negatives, 100 iter). Deterministic.
6. Ranking: average-tie rank of OOF probability over `valid` to [0,1]; similarly for global probability for final submission rank. No catalogue mask at this stage.
7. Holdout: shared `buffered_component_draw(grid, seed=20, buffer_px=3, boundary_px=12)` — whole connected components, globally hidden draw, visible = catalogue minus 3-px collar, 12-px boundary erosion, pixel-exact masking. Evaluator: shared `gems57.evaluate_holdout` pooled-DTI (alpha 0.2, beta 0.8, 300 m triangular kernel), paired 20 km cluster bootstrap 1000 draws seed 70420. Visible faults masked pixel-exactly.
8. Leakage canaries first: every raw used band and every derived feature (OOF prob, rank) alone, AUC on withheld positives vs 200k negatives (seed 70020). Any `max(AUC,1-AUC) >0.90` stops run as suspected leakage; no joint interpretation. All 39 raw AUCs recorded.
9. Dot emission: priority thinning — candidates in descending OOF-rank order from top 400k valid pixels, accept if no accepted dot within Euclidean distance <2.8 px, until 38,000 dots or pool exhaustion. Binary 1.0. Holdout dots use no catalogue exclusion (evaluator masks visible faults). Final submission dots additionally require `dcat >2 px`, refilled to 38,000 by same priority order (disclosed H33 hygiene, not claimed novel).
10. Arms (all HOLDOUT-DTI, same folds/masks): candidate OOF dots; ablations (step_oriented? not in this lane — instead: physics-only 19-feature model, lidar-only, rad-only) — but budget limits to primary + random + H33 reference for this session; additional ablations deferred. Random: 38,000 uniform valid pixels seed 70020 no thinning. References: H33 B2 37,654 SHA c55bafc..., D2.8 44,090 SHA 3e78737..., H19-5 solid 121k. Reference caveat: built with full-catalogue knowledge, so holdout values are reference measurements, not clean generalization.
11. Promotion bars (all required, candidate OOF dots, primary seed-20 draw): a) candidate DTI > every other arm point-wise; b) paired CI vs H33 excludes 0; c) CI vs random excludes 0; d) no canary alarm; e) surface Spearman ≤0.90 and final mutual overlap ≤0.70 on disclosed 62-raster check (both directions reported). If any bar fails, verdict negative, no TIFF promotion but diagnostic TIFF preserved as DO-NOT-SUBMIT for review.
12. Uniqueness: before placement, compare candidate surface (continuous) via Spearman only (no dot overlap on continuous); after placement, compare binary dots via `uniqueness.compare_array_to_registry` literal RHO_LIMIT 0.90 OVERLAP_LIMIT 0.70 mutual definition against 62 single-band 100 m rasters in /tmp/60GEMSDOE/registry/rasters (SHA-indexed). Any duplicate stops.
13. Writer: shared `submission_writer.write_submission` with pre-normalized float32 [0,1], all-finite, footprint-zero outside, catalogue-zero inside, sample for CRS/shape/transform, fail-closed temp+atomic replace, re-read + validator.
14. Budget: one experiment this lane, at most 3 total or 2 hours. No weekly slot spent until selector step; no organizer-confirmed score recorded without receipt.

## Scientific limits

Potential-field inversions non-unique; radiometrics see top 30 cm only; SGMC proxy may re-draw catalogue traces (20% within 3 px) and is not hidden organizer truth. Learning the proxy does not prove geothermal potential, temperature or permeability. HGB probabilities are not calibrated; ranking suffices for DTI.
