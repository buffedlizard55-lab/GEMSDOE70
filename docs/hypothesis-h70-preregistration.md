## Fixed first experiment — H70-A specification (pre-registered, no tuning on holdout)

- Inputs: `rtp` (band 2), `tmi_hg` (3), `tmi_vg` (9), `tmi` (14), `cond_surf` (17); all from pinned `training_features.tif`; descriptions in `evidence/feature_metadata.json`; no catalogue read by feature function.
- Preprocessing: Fill non-finite cells with nearest-finite (`scipy.ndimage.distance_transform_edt`), same as prior `physical_features`; valid = footprint ∩ finite on all 5 bands ∩ 12-px erosion (largest Gaussian truncation radius).
- Compute:
  - `cond_grad = Gaussian(σ=1) → ∇ → hypot → Gaussian(σ=2)` of `cond_surf`
  - `rtp_grad = hypot( ∂(Gaussian(rTP,σ=1))/∂y , ∂/∂x ) → Gaussian(σ=2)` of `rtp`
  - `analytic = √( tmi_hg² + tmi_vg² + rtp_grad² )` (total gradient including vertical derivative)
  - Fill analytic: `breach_raw = cond_grad * analytic` (cross-product; both ≥0); rank-breach = `rank01(breach_raw, valid)`
- Halo geometry (same as P4, comparable to H33 family): distance to nearest mapped trace `d = EDT(~catalogue_vis)`, tip kernel from `component_tips` (two principal-axis extremes per component) with `beyond = clip(u,0,∞)`, `tip = exp(-beyond/25) * exp(-|v|/8)`.
- Intensity: `off = exp(-((d - 2.4)/6)²)` for `d ≥ 2.4` else 0, band `d ≤ 32`; `tip_factor = 0.7 + 0.3·tip`; `breach_factor = 1 + 0.6·rank_breach`; `score = off · tip_factor · breach_factor`, masked `allowed = valid & ~catalogue_vis`.
- Placement: One dot per 7×7 px stratum at stratum-maximum of `score`, 5-px Euclidean NMS, exactly 37,654 binary dots (H33 budget), off-catalogue, zero outside footprint.
- Evaluation before promotion:
  - **Leakage canary:** Each raw input (`rtp`, `tmi_hg`, `tmi_vg`, `tmi`, `cond_surf`) and derived (`cond_grad`, `analytic`, `breach_raw`) alone: AUC and HOLDOUT-DTI on catalogue holdout; AUC >0.90 stops run as suspected leakage.
  - **Instrument A:** Shared `buffered_component_draw` seed 20, 4 quadrants, 3-px collar, 12-px boundary erosion; catalogue-derived predictor only from `visible`; pool weighted terms; paired 20-km spatial-cluster bootstrap 1000 draws, 95% CI; candidate vs random vs H33 reference.
  - **Instrument B/B′:** SGMC off-catalogue proxy (`ext_derived_sgmc_faults_100m_u8.tif`, sha 643cbe99…, via `data/external/derived_sgmc_faults_100m_u8.tif` manifest `ext_derived_sgmc_faults_100m_u8` from repo `buffedlizard55-lab/GEMSDOE24` ref `07345ea0604953d7efb858d9cfbc21e20c7aca0b`), split into 4 quadrants (LOQO), erosion 12 px; B′ excludes `d_cat < 3 px` duplication band (21.4% of SGMC-only pixels within 3 px, 12.5% within 2 px).
  - **Uniqueness gate (surface before placement AND final dots):** Against 62 single-band 100 m rasters archived in `buffedlizard55-lab/60GEMSDOE/registry/rasters` (inventory scope, not organizer exhaustive); Spearman ρ >0.90 or mutual `min(forward,reverse)` overlap >0.70 blocks; forward-only overlap reported separately and does not alone block (fix 2026-10-20: binary-dot definition `|value-1|<1e-6` and mutual-overlap requirement). If either check exceeds limit, stop, log duplicate, do not write submission.

Otherwise verdict `negative` and file is downloadable but `submit_recommended = false`. No weekly slot spent on failed gate.
