2 · What this file is and is not

  • Is: A per-pixel probability field (0=background, 1=fault) on the competition grid (EPSG:32611, 100m, 3730×3292). It is the output of H70-C: conductivity/depth structural boundary × directional coherence × transtensional relay indicator, greedy Poisson 300m packing, B=2 catalogue buffer.
  • Is not: The training labels reproduced. The scorer masks known USGS/INGENIOUS faults — predicting them back earns 0. This file has 0 dots on catalogue (and 0 within 200m).
  • Is not: An organizer score. Every HOLDOUT-DTI number is from a local spatially-blocked holdout (4 folds, visible faults masked pixel-exactly). Every ORGANIZER-CONFIRMED number is copied from a submission-page receipt. A projection is never written as a score.

5 · Click-by-click upload

  1. Log in at DrivenData and enroll in the competition (if not already).
  2. Go to Submissions → New submission.
  3. File to submit: click No file chosen → select the downloaded .tif (or .zip).
  4. Note (optional): paste the 138-char note above — helps your team tell submissions apart (e.g., “GEMSDOE70 H70-C relay-ramp …”).
  5. Click Create. The portal checks CRS/shape/transform and range [0,1] within seconds.
  6. You see a receipt with DTI on the public test set. Save it — only the platform's hidden new-fault labels can score it.

If the portal says Predicted values must be in range [0, 1]: You have a file with NaN or sentinel outside [0,1] inside the footprint. Re-download the zeros variant (not nan), and do not open/resave in a tool that injects nodata.

6 · Rules that bind this file

The scored population is not the training labels:

  • “In Phase 1, submissions will be evaluated against a privately withheld subset of the original new fault dataset compiled by expert reviewers.” — Rules PDF §3
  • “After Phase 1, expert reviewers will use submitted predictions to revise the new fault dataset.” — Rules PDF §4
  • “Submissions will be reevaluated against the full, revised new fault dataset using the same distance-weighted Tversky index.” — Rules PDF §4
  • “Pixels corresponding to known USGS/INGENIOUS faults are masked / excluded from evaluation” — forum 11516 (staff chrisk-dd, 2026-09-16)

All sentences quoted verbatim and verified via scripts/verify_rules_quotes.py against the SHA-pinned PDF.

7 · What to do with the score

Your public leaderboard DTI is the only organizer-verified number. Log it with the artifact SHA (36d2c3c4…) and the note you pasted. The Final Round will rescore the same submission you selected against the expanded label set — faults you flagged that experts confirm become part of the map. That is why sparse, geometrically clean, off-catalogue traces (dotted, B=2) are promoted over dense probability fields.
