Proof of the uniqueness conflict

Let F be the finite sample-footprint cells. For the fetched registry witness W, the measured support satisfies {x in F : W(x) > 0} = F. If a candidate has any nonempty support C contained in F, every c in C is also on positive witness support. Its nearest witness point is itself: distance zero. Thus count(c in C: distance(c, support(W)) <= 3) / count(C) = 1, exceeding the protocol limit. No choice of scientific hypothesis, dot placement, random seed, float perturbation or file name can make such a candidate pass. An all-zero raster avoids the denominator only by making a non-prediction; it is not a scientific discovery submission or an acceptable workaround.

This is a support/registry-definition conflict, not evidence that every possible geological method has the same mechanism. The decision to revise that protocol or registry is outside this lane. We did not exempt dense rasters, change the positivity threshold, stratify away failed comparisons, or continue placing dots after a duplicate.
